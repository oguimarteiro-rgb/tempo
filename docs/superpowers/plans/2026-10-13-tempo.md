# Tempo: plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rastreador de tempo manual, nativo do GNOME: indicador na barra (extensão do Shell) + app Python GTK4/libadwaita com relatório de gargalos, banco SQLite local, instalável com um script.

**Architecture:** Um processo Python (`Adw.Application`, id `br.com.oguim.Tempo`) é dono do banco, exporta a interface D-Bus `br.com.oguim.Tempo.Servico` em `/br/com/oguim/Tempo/Servico` e abre a janela sob demanda. A extensão do GNOME Shell (JavaScript ESM, GNOME 50) só desenha o indicador e traduz cliques em chamadas D-Bus. O núcleo (banco, entradas, gargalos, exportação, backup) é Python puro sem GTK, testado com pytest e SQLite em memória.

**Tech Stack:** Python 3.14, PyGObject 3.56 (Gtk 4.22, Adw 1.9, Gio), sqlite3 da stdlib, pytest 9; GNOME Shell 50 (gjs, St, PanelMenu); bash para `instalar.sh`.

**Spec:** `docs/superpowers/specs/2026-10-13-tempo-design.md`

## Global Constraints

- Idioma de código, mensagens e commits: português do Brasil, sem travessão `—`.
- Banco: `~/.local/share/tempo/tempo.db`; backups em `~/.local/share/tempo/backup/`, guardar 7.
- Datas em ISO 8601 com fuso: `datetime.now().astimezone().isoformat(timespec="seconds")`.
- No máximo uma entrada com `fim` nulo (índice único parcial + camada de serviço).
- Nome D-Bus: `br.com.oguim.Tempo`; interface `br.com.oguim.Tempo.Servico`; caminho `/br/com/oguim/Tempo/Servico`.
- Extensão UUID: `tempo@oguim.com`; schema GSettings `org.gnome.shell.extensions.tempo`; atalho padrão `<Super>t`.
- Núcleo Python nunca importa Gtk/Adw. Só `app/tempo/servico.py`, `app/tempo/app.py` e `app/tempo/janela/` tocam GObject.
- Testes: `cd app && python3 -m pytest -q`. Tudo verde antes de cada commit.
- Nada de serviço pago nos testes. Nada de D-Bus da sessão real nos testes: sempre `dbus-run-session`.
- Pacotes do sistema já presentes (verificado 2026-10-13): gtk4 4.22.5, libadwaita 1.9.4, python3-gobject 3.56.3, pytest 9.1.1, gjs, gnome-extensions, glib-compile-schemas, dbus-run-session.

```python
import sqlite3

SCHEMA = """
create table if not exists clientes(
  id integer primary key,
  nome text not null unique,
  cor text not null default '#3584e4',
  arquivado integer not null default 0
);
create table if not exists atividades(
  id integer primary key,
  nome text not null unique,
  cor text not null default '#3584e4',
  arquivado integer not null default 0
);
create table if not exists entradas(
  id integer primary key,
  inicio text not null,
  fim text,
  cliente_id integer references clientes(id),
  atividade_id integer references atividades(id),
  descricao text not null default ''
);
create unique index if not exists uma_aberta on entradas((fim is null)) where fim is null;
create index if not exists entradas_inicio on entradas(inicio);
"""

ATIVIDADES_PADRAO = [
    ("Edição", "#3584e4"), ("Captação", "#2ec27e"), ("Reunião", "#e66100"),
    ("Roteiro", "#9141ac"), ("Administrativo", "#c01c28"), ("Estudo", "#f5c211"),
    ("Deslocamento", "#5e5c64"),
]


def abrir(caminho=":memory:"):
    conn = sqlite3.connect(caminho)
    conn.row_factory = sqlite3.Row
    conn.execute("pragma foreign_keys = on")
    conn.executescript(SCHEMA)
    if conn.execute("select count(*) from atividades").fetchone()[0] == 0:
        conn.executemany("insert into atividades(nome, cor) values(?, ?)", ATIVIDADES_PADRAO)
        conn.commit()
    return conn
```

```python
import sqlite3

TABELAS = ("clientes", "atividades")


def _validar(tabela):
    if tabela not in TABELAS:
        raise ValueError(f"tabela inválida: {tabela}")


def _dict(row):
    return {"id": row["id"], "nome": row["nome"], "cor": row["cor"], "arquivado": bool(row["arquivado"])}


def listar(conn, tabela, incluir_arquivados=False):
    _validar(tabela)
    sql = f"select * from {tabela}"
    if not incluir_arquivados:
        sql += " where arquivado = 0"
    return [_dict(r) for r in conn.execute(sql + " order by nome collate nocase")]


def criar(conn, tabela, nome, cor="#3584e4"):
    _validar(tabela)
    try:
        cur = conn.execute(f"insert into {tabela}(nome, cor) values(?, ?)", (nome.strip(), cor))
    except sqlite3.IntegrityError:
        raise ValueError(f"já existe {tabela[:-1]} chamado {nome!r}")
    conn.commit()
    return cur.lastrowid


def renomear(conn, tabela, id, nome):
    _validar(tabela)
    conn.execute(f"update {tabela} set nome = ? where id = ?", (nome.strip(), id))
    conn.commit()


def trocar_cor(conn, tabela, id, cor):
    _validar(tabela)
    conn.execute(f"update {tabela} set cor = ? where id = ?", (cor, id))
    conn.commit()


def arquivar(conn, tabela, id, arquivado=True):
    _validar(tabela)
    conn.execute(f"update {tabela} set arquivado = ? where id = ?", (1 if arquivado else 0, id))
    conn.commit()
```

### Task 2: Entradas (iniciar, parar, trocar, editar, listar, recentes)

**Files:**
- Create: `app/tempo/entradas.py`
- Test: `app/tests/test_entradas.py`

**Interfaces:**
- Consumes: `banco.abrir`, `cadastros.criar`.
- Produces (todas recebem `conn`; `agora` é `datetime` com fuso, padrão `datetime.now().astimezone()`):
  - `iniciar(conn, cliente_id, atividade_id, descricao="", agora=None) -> int`: encerra a aberta no mesmo instante, cria nova, devolve id.
  - `parar(conn, agora=None) -> bool`: False se não havia aberta.
  - `atual(conn) -> dict | None`
  - `por_id(conn, id) -> dict | None`
  - `do_dia(conn, dia: date) -> list[dict]` (ordenadas por inicio)
  - `no_periodo(conn, de: date, ate: date) -> list[dict]` (inclusive nos dois lados, só entradas fechadas)
  - `criar_manual(conn, inicio, fim, cliente_id, atividade_id, descricao="") -> int` (ValueError se fim <= inicio)
  - `editar(conn, id, **campos)` campos entre `inicio, fim, cliente_id, atividade_id, descricao`
  - `apagar(conn, id)`
  - `recentes(conn, n=5) -> list[dict]` combinações distintas cliente_id+atividade_id mais recentes, com `cliente`, `atividade`, `cor`.
  - Formato de dict de entrada: `{"id", "inicio" (str ISO), "fim" (str ISO ou None), "cliente_id", "atividade_id", "descricao", "cliente" (nome ou ""), "atividade" (nome ou ""), "cor" (cor do cliente ou "#3584e4"), "minutos" (int, até fim ou até agora se aberta)}`.
  - `fmt(dt: datetime) -> str` e `parse(s: str) -> datetime` helpers de ISO com fuso.

```python
from datetime import datetime, date, timedelta

CAMPOS_EDITAVEIS = {"inicio", "fim", "cliente_id", "atividade_id", "descricao"}

SELECT = """
select e.*, c.nome as cliente, c.cor as cor, a.nome as atividade
from entradas e
left join clientes c on c.id = e.cliente_id
left join atividades a on a.id = e.atividade_id
"""


def agora_local():
    return datetime.now().astimezone()


def fmt(dt):
    if isinstance(dt, str):
        return dt
    if dt.tzinfo is None:
        dt = dt.astimezone()
    return dt.isoformat(timespec="seconds")


def parse(s):
    return datetime.fromisoformat(s)


def _dict(row, agora=None):
    fim = row["fim"]
    ini = parse(row["inicio"])
    fim_dt = parse(fim) if fim else (agora or agora_local())
    return {
        "id": row["id"], "inicio": row["inicio"], "fim": fim,
        "cliente_id": row["cliente_id"], "atividade_id": row["atividade_id"],
        "descricao": row["descricao"], "cliente": row["cliente"] or "",
        "atividade": row["atividade"] or "", "cor": row["cor"] or "#3584e4",
        "minutos": int((fim_dt - ini).total_seconds() // 60),
    }


def atual(conn, agora=None):
    row = conn.execute(SELECT + " where e.fim is null").fetchone()
    return _dict(row, agora) if row else None


def por_id(conn, id, agora=None):
    row = conn.execute(SELECT + " where e.id = ?", (id,)).fetchone()
    return _dict(row, agora) if row else None


def iniciar(conn, cliente_id, atividade_id, descricao="", agora=None):
    agora = agora or agora_local()
    parar(conn, agora)
    cur = conn.execute(
        "insert into entradas(inicio, cliente_id, atividade_id, descricao) values(?,?,?,?)",
        (fmt(agora), cliente_id, atividade_id, descricao.strip()),
    )
    conn.commit()
    return cur.lastrowid


def parar(conn, agora=None):
    agora = agora or agora_local()
    cur = conn.execute("update entradas set fim = ? where fim is null", (fmt(agora),))
    conn.commit()
    return cur.rowcount > 0


def criar_manual(conn, inicio, fim, cliente_id, atividade_id, descricao=""):
    if parse(fmt(fim)) <= parse(fmt(inicio)):
        raise ValueError("fim precisa ser depois do início")
    cur = conn.execute(
        "insert into entradas(inicio, fim, cliente_id, atividade_id, descricao) values(?,?,?,?,?)",
        (fmt(inicio), fmt(fim), cliente_id, atividade_id, descricao.strip()),
    )
    conn.commit()
    return cur.lastrowid


def editar(conn, id, **campos):
    invalidos = set(campos) - CAMPOS_EDITAVEIS
    if invalidos:
        raise ValueError(f"campos inválidos: {sorted(invalidos)}")
    if not campos:
        return
    valores = {k: (fmt(v) if k in ("inicio", "fim") and v is not None else v) for k, v in campos.items()}
    sets = ", ".join(f"{k} = ?" for k in valores)
    conn.execute(f"update entradas set {sets} where id = ?", (*valores.values(), id))
    conn.commit()


def apagar(conn, id):
    conn.execute("delete from entradas where id = ?", (id,))
    conn.commit()


def _limites(de, ate):
    ini = datetime.combine(de, datetime.min.time()).astimezone()
    fim = datetime.combine(ate + timedelta(days=1), datetime.min.time()).astimezone()
    return fmt(ini), fmt(fim)


def do_dia(conn, dia, agora=None):
    ini, fim = _limites(dia, dia)
    rows = conn.execute(SELECT + " where e.inicio >= ? and e.inicio < ? order by e.inicio", (ini, fim))
    return [_dict(r, agora) for r in rows]


def no_periodo(conn, de, ate):
    ini, fim = _limites(de, ate)
    rows = conn.execute(
        SELECT + " where e.fim is not null and e.inicio >= ? and e.inicio < ? order by e.inicio", (ini, fim)
    )
    return [_dict(r) for r in rows]


def recentes(conn, n=5):
    rows = conn.execute(
        """
        select e.cliente_id, e.atividade_id, c.nome as cliente, c.cor as cor, a.nome as atividade,
               max(e.inicio) as ultimo
        from entradas e
        left join clientes c on c.id = e.cliente_id
        left join atividades a on a.id = e.atividade_id
        where (c.arquivado is null or c.arquivado = 0) and (a.arquivado is null or a.arquivado = 0)
        group by e.cliente_id, e.atividade_id
        order by ultimo desc limit ?
        """,
        (n,),
    )
    return [
        {"cliente_id": r["cliente_id"], "atividade_id": r["atividade_id"], "cliente": r["cliente"] or "",
         "atividade": r["atividade"] or "", "cor": r["cor"] or "#3584e4"}
        for r in rows
    ]
```

Observação para o implementador: `_limites` usa o fuso local da máquina de teste; os testes usam T0 com fuso -03:00 e comparam só por data de início, então valem em qualquer fuso brasileiro. Se um teste de `do_dia` falhar por fuso, compare com `date.fromisoformat(e["inicio"][:10])` em vez de ajustar a hora.

```python
from tempo import entradas

LIMITE_MINUTOS = 12 * 60
MODOS = ("inicio", "agora", "descartar")


def detectar(conn, inicio_sessao):
    e = entradas.atual(conn)
    if e and entradas.parse(e["inicio"]) < inicio_sessao:
        return e
    return None


def resolver(conn, modo, agora=None):
    if modo not in MODOS:
        raise ValueError(f"modo inválido: {modo}")
    e = entradas.atual(conn)
    if not e:
        return
    if modo == "inicio":
        entradas.editar(conn, e["id"], fim=e["inicio"])
    elif modo == "agora":
        entradas.parar(conn, agora)
    else:
        entradas.apagar(conn, e["id"])


def passou_de_12h(entrada):
    return bool(entrada) and entrada["minutos"] >= LIMITE_MINUTOS
```

```python
from collections import Counter, defaultdict
from datetime import date, timedelta, datetime

DIAS = ["Seg", "Ter", "Qua", "Qui", "Sex", "Sáb", "Dom"]
DIAS_LONGO = ["Segunda", "Terça", "Quarta", "Quinta", "Sexta", "Sábado", "Domingo"]
COR_PADRAO = "#3584e4"
LIMIAR_CRESCIMENTO = 0.25


def total_minutos(entradas):
    return sum(e["minutos"] for e in entradas)


def fmt_h(minutos):
    h, m = divmod(int(minutos), 60)
    if h == 0:
        return f"{m}min"
    if m == 0:
        return f"{h}h"
    return f"{h}h{m:02d}"


def _agrupar(entradas, chave, cor_de):
    mins = defaultdict(int)
    cores = {}
    for e in entradas:
        k = e[chave] or "(sem)"
        mins[k] += e["minutos"]
        cores.setdefault(k, cor_de(e))
    return sorted(((k, v, cores[k]) for k, v in mins.items()), key=lambda x: -x[1])


def por_cliente(entradas):
    return _agrupar(entradas, "cliente", lambda e: e["cor"])


def por_atividade(entradas):
    return _agrupar(entradas, "atividade", lambda e: e["cor"])


def _dia_semana(e):
    return datetime.fromisoformat(e["inicio"]).weekday()


def por_dia_semana(entradas):
    mins = [0] * 7
    for e in entradas:
        mins[_dia_semana(e)] += e["minutos"]
    return [(DIAS[i], mins[i], COR_PADRAO) for i in range(7)]


def periodo(nome, hoje, de=None, ate=None):
    if nome == "esta_semana":
        ini = hoje - timedelta(days=hoje.weekday())
        return ini, ini + timedelta(days=6)
    if nome == "semana_passada":
        ini = hoje - timedelta(days=hoje.weekday() + 7)
        return ini, ini + timedelta(days=6)
    if nome == "este_mes":
        ini = hoje.replace(day=1)
        prox = (ini.replace(day=28) + timedelta(days=4)).replace(day=1)
        return ini, prox - timedelta(days=1)
    if nome == "personalizado":
        return de, ate
    raise ValueError(f"período inválido: {nome}")


def periodo_anterior(de, ate):
    tamanho = (ate - de).days + 1
    return de - timedelta(days=tamanho), de - timedelta(days=1)


def _leitura_crescimento(atual, anterior):
    if not anterior:
        return None
    a = {k: v for k, v, _ in por_atividade(atual)}
    b = {k: v for k, v, _ in por_atividade(anterior)}
    melhor = None
    for k, v in a.items():
        base = b.get(k, 0)
        if base == 0:
            continue
        cresc = (v - base) / base
        if cresc >= LIMIAR_CRESCIMENTO and (melhor is None or cresc > melhor[1]):
            melhor = (k, cresc)
    if not melhor:
        return None
    return f"{melhor[0]} subiu {round(melhor[1] * 100)}% em relação ao período anterior."


def _leitura_cliente(atual):
    clientes = por_cliente(atual)
    if not clientes:
        return None
    nome, mins, _ = clientes[0]
    do_cliente = [e for e in atual if (e["cliente"] or "(sem)") == nome]
    atividade = por_atividade(do_cliente)[0][0]
    return f"{nome}: {fmt_h(mins)}, maior parte em {atividade}."


def _leitura_fragmentacao(atual):
    por_dia = Counter(datetime.fromisoformat(e["inicio"]).date() for e in atual)
    if not por_dia:
        return None
    dia, trocas = por_dia.most_common(1)[0]
    if trocas < 4:
        return None
    return f"{DIAS_LONGO[dia.weekday()]} foi o dia mais fragmentado: {trocas} trocas de tarefa."


def _leitura_total(atual):
    if not atual:
        return None
    dias = len({datetime.fromisoformat(e["inicio"]).date() for e in atual})
    total = total_minutos(atual)
    return f"Total de {fmt_h(total)} em {dias} dias, média de {fmt_h(total // dias)} por dia."


def leituras(atual, anterior):
    frases = [
        _leitura_crescimento(atual, anterior),
        _leitura_cliente(atual),
        _leitura_fragmentacao(atual),
        _leitura_total(atual),
    ]
    return [f for f in frases if f]
```

```python
import shutil
from pathlib import Path


def fazer(db_path, pasta, hoje, guardar=7):
    db_path, pasta = Path(db_path), Path(pasta)
    pasta.mkdir(parents=True, exist_ok=True)
    destino = pasta / f"tempo-{hoje.isoformat()}.db"
    if destino.exists():
        return None
    shutil.copy2(db_path, destino)
    antigos = sorted(pasta.glob("tempo-*.db"))
    for p in antigos[:-guardar]:
        p.unlink()
    return destino
```

```python
import json
from datetime import datetime

import gi
gi.require_version("Gio", "2.0")
from gi.repository import Gio, GLib

from tempo import VERSAO, cadastros, entradas, esquecida

INTERFACE = "br.com.oguim.Tempo.Servico"
CAMINHO = "/br/com/oguim/Tempo/Servico"
NOME = "br.com.oguim.Tempo"

XML = f"""<node>
<interface name="{INTERFACE}">
  <method name="Iniciar">
    <arg type="i" name="cliente_id" direction="in"/>
    <arg type="i" name="atividade_id" direction="in"/>
    <arg type="s" name="descricao" direction="in"/>
    <arg type="i" name="id" direction="out"/>
  </method>
  <method name="Parar"><arg type="b" name="parou" direction="out"/></method>
  <method name="EntradaAtual"><arg type="s" name="json" direction="out"/></method>
  <method name="Recentes"><arg type="s" name="json" direction="out"/></method>
  <method name="Clientes"><arg type="s" name="json" direction="out"/></method>
  <method name="Atividades"><arg type="s" name="json" direction="out"/></method>
  <method name="Esquecida"><arg type="s" name="json" direction="out"/></method>
  <method name="ResolverEsquecida"><arg type="s" name="modo" direction="in"/></method>
  <method name="AbrirJanela"/>
  <method name="Versao"><arg type="s" name="versao" direction="out"/></method>
  <signal name="EntradaMudou"><arg type="s" name="json"/></signal>
</interface>
</node>"""

ASSINATURAS = {
    "Iniciar": "(i)", "Parar": "(b)", "EntradaAtual": "(s)", "Recentes": "(s)", "Clientes": "(s)",
    "Atividades": "(s)", "Esquecida": "(s)", "ResolverEsquecida": "()", "AbrirJanela": "()", "Versao": "(s)",
}


class Servico:
    def __init__(self, conn, emitir, abrir_janela, inicio_sessao=None):
        self.conn = conn
        self.emitir = emitir
        self.abrir_janela = abrir_janela
        self.inicio_sessao = inicio_sessao or datetime.now().astimezone()

    def notificar(self):
        self.emitir(json.dumps(entradas.atual(self.conn)))

    def chamar(self, nome, args):
        if nome == "Iniciar":
            cid, aid, desc = args
            eid = entradas.iniciar(self.conn, cid, aid, desc)
            self.notificar()
            return (eid,)
        if nome == "Parar":
            parou = entradas.parar(self.conn)
            self.notificar()
            return (parou,)
        if nome == "EntradaAtual":
            return (json.dumps(entradas.atual(self.conn)),)
        if nome == "Recentes":
            return (json.dumps(entradas.recentes(self.conn)),)
        if nome == "Clientes":
            return (json.dumps(cadastros.listar(self.conn, "clientes")),)
        if nome == "Atividades":
            return (json.dumps(cadastros.listar(self.conn, "atividades")),)
        if nome == "Esquecida":
            return (json.dumps(esquecida.detectar(self.conn, self.inicio_sessao)),)
        if nome == "ResolverEsquecida":
            esquecida.resolver(self.conn, args[0])
            self.notificar()
            return ()
        if nome == "AbrirJanela":
            self.abrir_janela()
            return ()
        if nome == "Versao":
            return (VERSAO,)
        raise ValueError(f"método desconhecido: {nome}")


def registrar(conn_dbus, caminho, servico):
    info = Gio.DBusNodeInfo.new_for_xml(XML)

    def on_call(conn, sender, path, iface, method, params, inv):
        try:
            res = servico.chamar(method, params.unpack())
            inv.return_value(GLib.Variant(ASSINATURAS[method], res))
        except Exception as e:  # erro vira erro D-Bus legível, não derruba o serviço
            inv.return_dbus_error("br.com.oguim.Tempo.Erro", str(e))

    return conn_dbus.register_object(caminho, info.interfaces[0], on_call, None, None)


def emissor(conn_dbus, caminho):
    def emitir(json_str):
        conn_dbus.emit_signal(None, caminho, INTERFACE, "EntradaMudou", GLib.Variant("(s)", (json_str,)))
    return emitir
```

```python
from gi.repository import Adw, Gtk

from tempo import cadastros, entradas, gargalos


def _hhmm(iso):
    return iso[11:16] if iso else "…"


class PaginaHoje(Gtk.Box):
    def __init__(self, app):
        super().__init__(orientation=Gtk.Orientation.VERTICAL, spacing=12, margin_top=12, margin_bottom=12,
                         margin_start=12, margin_end=12)
        self.app = app
        topo = Gtk.Box(spacing=6)
        self.titulo = Gtk.Label(xalign=0, css_classes=["title-2"])
        topo.append(self.titulo)
        topo.append(Gtk.Box(hexpand=True))
        btn = Gtk.Button(icon_name="list-add-symbolic", tooltip_text="Adicionar entrada manual")
        btn.connect("clicked", lambda *_: DialogoEntrada(self.get_root(), self.app, None, self.atualizar).present(self.get_root()))
        topo.append(btn)
        self.append(topo)
        self.lista = Gtk.ListBox(css_classes=["boxed-list"], selection_mode=Gtk.SelectionMode.NONE)
        scroll = Gtk.ScrolledWindow(vexpand=True, child=self.lista)
        self.append(scroll)
        self.total = Gtk.Label(xalign=1, css_classes=["dim-label"])
        self.append(self.total)

    def atualizar(self):
        hoje = date.today()
        self.titulo.set_text(hoje.strftime("%A, %d/%m").capitalize())
        while (filho := self.lista.get_first_child()) is not None:
            self.lista.remove(filho)
        lista = entradas.do_dia(self.app.conn, hoje)
        for e in lista:
            row = Adw.ActionRow(title=f"{e['cliente']} · {e['atividade']}", subtitle=e["descricao"], activatable=True)
            row.add_suffix(Gtk.Label(label=f"{_hhmm(e['inicio'])}–{_hhmm(e['fim'])}   {gargalos.fmt_h(e['minutos'])}",
                                     css_classes=["numeric"]))
            row.connect("activated", lambda _r, ent=e: DialogoEntrada(self.get_root(), self.app, ent, self.atualizar).present(self.get_root()))
            self.lista.append(row)
        self.total.set_text(f"Total do dia: {gargalos.fmt_h(gargalos.total_minutos(lista))}")


class DialogoEntrada(Adw.AlertDialog):
    def __init__(self, janela, app, entrada, depois):
        super().__init__(heading="Editar entrada" if entrada else "Nova entrada")
        self.app, self.entrada, self.depois, self.janela = app, entrada, depois, janela
        grupo = Adw.PreferencesGroup()
        self.desc = Adw.EntryRow(title="Descrição", text=(entrada or {}).get("descricao", ""))
        self.clientes = cadastros.listar(app.conn, "clientes")
        self.atividades = cadastros.listar(app.conn, "atividades")
        self.cli = self._combo("Cliente", self.clientes, (entrada or {}).get("cliente_id"))
        self.ati = self._combo("Atividade", self.atividades, (entrada or {}).get("atividade_id"))
        self.ini = Adw.EntryRow(title="Início (HH:MM)", text=_hhmm((entrada or {}).get("inicio")) if entrada else "")
        self.fim = Adw.EntryRow(title="Fim (HH:MM)", text=_hhmm((entrada or {}).get("fim")) if entrada and entrada.get("fim") else "")
        for w in (self.desc, self.cli, self.ati, self.ini, self.fim):
            grupo.add(w)
        self.set_extra_child(grupo)
        self.add_response("cancelar", "Cancelar")
        if entrada:
            self.add_response("apagar", "Apagar")
            self.set_response_appearance("apagar", Adw.ResponseAppearance.DESTRUCTIVE)
        self.add_response("salvar", "Salvar")
        self.set_response_appearance("salvar", Adw.ResponseAppearance.SUGGESTED)
        self.set_default_response("salvar")
        self.connect("response", self._on_resp)

    def _combo(self, titulo, itens, selecionado):
        combo = Adw.ComboRow(title=titulo)
        modelo = Gtk.StringList.new([i["nome"] for i in itens])
        combo.set_model(modelo)
        for idx, i in enumerate(itens):
            if i["id"] == selecionado:
                combo.set_selected(idx)
        return combo

    def _hora(self, texto, base_iso):
        h, m = texto.strip().split(":")
        dia = datetime.fromisoformat(base_iso).date() if base_iso else date.today()
        return datetime.combine(dia, time(int(h), int(m))).astimezone()

    def _on_resp(self, _d, resp):
        try:
            if resp == "apagar":
                entradas.apagar(self.app.conn, self.entrada["id"])
            elif resp == "salvar":
                if not self.clientes or not self.atividades:
                    raise ValueError("cadastre pelo menos um cliente e uma atividade")
                cid = self.clientes[self.cli.get_selected()]["id"]
                aid = self.atividades[self.ati.get_selected()]["id"]
                base = (self.entrada or {}).get("inicio")
                ini = self._hora(self.ini.get_text(), base)
                fim_txt = self.fim.get_text().strip()
                fim = self._hora(fim_txt, base) if fim_txt else None
                if self.entrada:
                    campos = dict(descricao=self.desc.get_text(), cliente_id=cid, atividade_id=aid, inicio=ini)
                    if fim is not None:
                        if fim <= ini:
                            raise ValueError("fim precisa ser depois do início")
                        campos["fim"] = fim
                    entradas.editar(self.app.conn, self.entrada["id"], **campos)
                else:
                    if fim is None:
                        raise ValueError("entrada manual precisa de fim")
                    entradas.criar_manual(self.app.conn, ini, fim, cid, aid, self.desc.get_text())
            else:
                return
            self.app.servico.notificar()
            self.depois()
        except (ValueError, IndexError) as e:
            self.janela.toast(f"Não salvou: {e}")
```

```python
import gi
gi.require_version("Gtk", "4.0")
from gi.repository import Gtk, Gdk

from tempo import gargalos

ALTURA_BARRA = 22
ESPACO = 8
LARGURA_ROTULO = 110
LARGURA_VALOR = 56


class Barras(Gtk.Box):
    def __init__(self, titulo):
        super().__init__(orientation=Gtk.Orientation.VERTICAL, spacing=6)
        self.append(Gtk.Label(label=titulo, xalign=0, css_classes=["heading"]))
        self.area = Gtk.DrawingArea(hexpand=True)
        self.area.set_draw_func(self._desenhar)
        self.append(self.area)
        self.dados = []

    def set_dados(self, dados):
        self.dados = list(dados)
        self.area.set_content_height(max(1, len(self.dados)) * (ALTURA_BARRA + ESPACO))
        self.area.queue_draw()

    def _desenhar(self, area, cr, w, h):
        cor_texto = area.get_color()
        cr.set_source_rgba(cor_texto.red, cor_texto.green, cor_texto.blue, cor_texto.alpha)
        cr.set_font_size(13)
        if not self.dados:
            cr.move_to(0, 16)
            cr.show_text("Sem dados")
            return
        maximo = max(v for _, v, _ in self.dados) or 1
        largura_util = max(10, w - LARGURA_ROTULO - LARGURA_VALOR)
        for i, (nome, valor, cor) in enumerate(self.dados):
            y = i * (ALTURA_BARRA + ESPACO)
            cr.set_source_rgba(cor_texto.red, cor_texto.green, cor_texto.blue, cor_texto.alpha)
            cr.move_to(0, y + 16)
            cr.show_text(nome[:16])
            rgba = Gdk.RGBA()
```

```python
import gi
gi.require_version("Gtk", "4.0")
gi.require_version("Adw", "1")
from gi.repository import Adw, Gdk, Gtk

from tempo import cadastros


class PaginaCadastros(Gtk.Box):
    def __init__(self, app):
        super().__init__(orientation=Gtk.Orientation.VERTICAL, spacing=18, margin_top=12, margin_bottom=12,
                         margin_start=12, margin_end=12)
        self.app = app
        self.grupos = {}
        scroll = Gtk.ScrolledWindow(vexpand=True)
        caixa = Gtk.Box(orientation=Gtk.Orientation.VERTICAL, spacing=18)
        scroll.set_child(caixa)
        for tabela, titulo in (("clientes", "Clientes"), ("atividades", "Atividades")):
            grupo = Adw.PreferencesGroup(title=titulo)
            btn = Gtk.Button(icon_name="list-add-symbolic", css_classes=["flat"], tooltip_text=f"Novo em {titulo}")
            btn.connect("clicked", lambda _b, t=tabela: self._dialogo_nome(t, None))
            grupo.set_header_suffix(btn)
            caixa.append(grupo)
            self.grupos[tabela] = (grupo, [])
        self.append(scroll)

    def atualizar(self):
        for tabela, (grupo, linhas) in self.grupos.items():
            for l in linhas:
                grupo.remove(l)
            linhas.clear()
            for item in cadastros.listar(self.app.conn, tabela, incluir_arquivados=True):
                row = Adw.ActionRow(title=item["nome"], activatable=True)
                if item["arquivado"]:
                    row.add_css_class("dim-label")
                cor = Gtk.ColorDialogButton(dialog=Gtk.ColorDialog(with_alpha=False), valign=Gtk.Align.CENTER)
                rgba = Gdk.RGBA(); rgba.parse(item["cor"]); cor.set_rgba(rgba)
                cor.connect("notify::rgba", lambda b, _p, t=tabela, i=item["id"]: self._trocar_cor(t, i, b.get_rgba()))
                row.add_prefix(cor)
                sw = Gtk.Switch(active=not item["arquivado"], valign=Gtk.Align.CENTER, tooltip_text="Ativo")
                sw.connect("state-set", lambda _s, ativo, t=tabela, i=item["id"]: self._arquivar(t, i, not ativo))
                row.add_suffix(sw)
                row.connect("activated", lambda _r, t=tabela, it=item: self._dialogo_nome(t, it))
                grupo.add(row)
                linhas.append(row)

    def _hex(self, rgba):
        return "#%02x%02x%02x" % (round(rgba.red * 255), round(rgba.green * 255), round(rgba.blue * 255))

    def _trocar_cor(self, tabela, id, rgba):
        cadastros.trocar_cor(self.app.conn, tabela, id, self._hex(rgba))
        self.app.servico.notificar()

    def _arquivar(self, tabela, id, arquivado):
        cadastros.arquivar(self.app.conn, tabela, id, arquivado)
        self.app.servico.notificar()
        self.atualizar()
        return False

    def _dialogo_nome(self, tabela, item):
        d = Adw.AlertDialog(heading="Renomear" if item else "Novo")
        entry = Adw.EntryRow(title="Nome", text=item["nome"] if item else "")
        grupo = Adw.PreferencesGroup(); grupo.add(entry)
        d.set_extra_child(grupo)
        d.add_response("cancelar", "Cancelar")
        d.add_response("salvar", "Salvar")
        d.set_response_appearance("salvar", Adw.ResponseAppearance.SUGGESTED)
        d.set_default_response("salvar")

        def on_resp(_d, resp):
            if resp != "salvar":
                return
            nome = entry.get_text().strip()
            try:
                if not nome:
                    raise ValueError("nome vazio")
                if item:
                    cadastros.renomear(self.app.conn, tabela, item["id"], nome)
                else:
                    cadastros.criar(self.app.conn, tabela, nome)
                self.app.servico.notificar()
                self.atualizar()
            except ValueError as e:
                self.get_root().toast(f"Não salvou: {e}")
        d.connect("response", on_resp)
        d.present(self.get_root())
```

```javascript
import * as PopupMenu from 'resource:///org/gnome/shell/ui/popupMenu.js';

const NOME = 'br.com.oguim.Tempo';
const CAMINHO = '/br/com/oguim/Tempo/Servico';
const IFACE = `<node><interface name="br.com.oguim.Tempo.Servico">
  <method name="Iniciar"><arg type="i" direction="in"/><arg type="i" direction="in"/><arg type="s" direction="in"/><arg type="i" direction="out"/></method>
  <method name="Parar"><arg type="b" direction="out"/></method>

</interface></node>`;
const Proxy = Gio.DBusProxy.makeProxyWrapper(IFACE);

function fmtDuracao(iso) {
    const ini = GLib.DateTime.new_from_iso8601(iso, null);
    if (!ini) return '00:00';
    const seg = Math.max(0, GLib.DateTime.new_now_local().difference(ini) / 1e6);
    const h = Math.floor(seg / 3600), m = Math.floor((seg % 3600) / 60), s = Math.floor(seg % 60);
    return h > 0 ? `${h}:${String(m).padStart(2, '0')}:${String(s).padStart(2, '0')}`
                 : `${String(m).padStart(2, '0')}:${String(s).padStart(2, '0')}`;
}

const Indicador = GObject.registerClass(
class Indicador extends PanelMenu.Button {
    _init() {
        super._init(0.5, 'Tempo');
        this._caixa = new St.BoxLayout({style_class: 'panel-status-menu-box'});
        this._ponto = new St.Label({text: '●', y_align: Clutter.ActorAlign.CENTER, visible: false});
        this._icone = new St.Icon({icon_name: 'alarm-symbolic', style_class: 'system-status-icon'});
        this._rotulo = new St.Label({text: '', y_align: Clutter.ActorAlign.CENTER});
        this._caixa.add_child(this._ponto);
        this._caixa.add_child(this._icone);
        this._caixa.add_child(this._rotulo);
        this.add_child(this._caixa);

        this._entrada = null;
        this._clientes = [];
        this._atividades = [];
        this._clienteSel = null;
        this._atividadeSel = null;
        this._tick = 0;

        this._montarMenu();
        this._proxy = new Proxy(Gio.DBus.session, NOME, CAMINHO, (p, erro) => {
            if (erro) { this._semServico(); return; }
            this._sinalId = this._proxy.connectSignal('EntradaMudou', (_p, _s, [json]) => this._aplicar(json));
            this._recarregar();
        });
        this.menu.connect('open-state-changed', (_m, aberto) => { if (aberto) this._recarregar(); });

        this._btn.connect('activate', () => this._iniciarOuParar());
        this.menu.addMenuItem(this._btn);

        const campo = new PopupMenu.PopupBaseMenuItem({reactive: false, can_focus: false});
        this._desc = new St.Entry({hint_text: 'Descrição (opcional)', x_expand: true, can_focus: true});
        campo.add_child(this._desc);
        this.menu.addMenuItem(campo);

        this._subCli = new PopupMenu.PopupSubMenuMenuItem('Cliente');

        this.menu.addMenuItem(this._subCli);
        this.menu.addMenuItem(this._subAti);

        this.menu.addMenuItem(new PopupMenu.PopupSeparatorMenuItem('Recentes'));
        this._recentes = new PopupMenu.PopupMenuSection();
        this.menu.addMenuItem(this._recentes);

        this.menu.addMenuItem(new PopupMenu.PopupSeparatorMenuItem());
        const abrir = new PopupMenu.PopupMenuItem('Abrir relatório');

        this.menu.addMenuItem(abrir);
        this._reconectar = new PopupMenu.PopupMenuItem('Reconectar ao serviço');
        this._reconectar.connect('activate', () => this._recarregar());
        this._reconectar.visible = false;
        this.menu.addMenuItem(this._reconectar);
    }

    _semServico() {
        this._icone.opacity = 120;
        this._rotulo.text = '';
        this._ponto.visible = false;
        this._reconectar.visible = true;
        this._pararTick();
    }

    _recarregar() {
        if (!this._proxy) return;
        this._proxy.EntradaAtualRemote((r, e) => {
            if (e) { this._semServico(); return; }
            this._icone.opacity = 255;
            this._reconectar.visible = false;
            this._aplicar(r[0]);
        });
        this._proxy.ClientesRemote((r, e) => { if (!e) { this._clientes = JSON.parse(r[0]); this._preencher(this._subCli, this._clientes, 'cliente'); } });
        this._proxy.AtividadesRemote((r, e) => { if (!e) { this._atividades = JSON.parse(r[0]); this._preencher(this._subAti, this._atividades, 'atividade'); } });
        this._proxy.RecentesRemote((r, e) => { if (!e) this._preencherRecentes(JSON.parse(r[0])); });
    }

    _preencher(sub, itens, tipo) {
        sub.menu.removeAll();
        const selId = tipo === 'cliente' ? this._clienteSel : this._atividadeSel;
        const sel = itens.find(i => i.id === selId) ?? itens[0] ?? null;
        if (tipo === 'cliente') this._clienteSel = sel?.id ?? null; else this._atividadeSel = sel?.id ?? null;
        sub.label.text = `${tipo === 'cliente' ? 'Cliente' : 'Atividade'}: ${sel ? sel.nome : '(nenhum)'}`;
        for (const it of itens) {
            const item = new PopupMenu.PopupMenuItem(it.nome);
            item.connect('activate', () => {
                if (tipo === 'cliente') this._clienteSel = it.id; else this._atividadeSel = it.id;
                sub.label.text = `${tipo === 'cliente' ? 'Cliente' : 'Atividade'}: ${it.nome}`;
            });
            sub.menu.addMenuItem(item);
        }
    }

    _preencherRecentes(lista) {
        this._recentes.removeAll();
        for (const r of lista) {
            const item = new PopupMenu.PopupMenuItem(`${r.cliente} · ${r.atividade}`);
            item.connect('activate', () => this._proxy.IniciarRemote(r.cliente_id, r.atividade_id, '', () => {}));
            this._recentes.addMenuItem(item);
        }
    }

    _iniciarOuParar() {
        if (!this._proxy) return;
        if (this._entrada) {
            this._proxy.PararRemote(() => {});
        } else if (this._clienteSel != null && this._atividadeSel != null) {
            this._proxy.IniciarRemote(this._clienteSel, this._atividadeSel, this._desc.get_text(), () => { this._desc.set_text(''); });
        } else {
            Main.notify('Tempo', 'Cadastre um cliente e uma atividade no relatório antes de iniciar.');
        }
    }

    _aplicar(json) {
        this._entrada = json && json !== 'null' ? JSON.parse(json) : null;
        if (this._entrada) {
            this._clienteSel = this._entrada.cliente_id;
            this._atividadeSel = this._entrada.atividade_id;
            this._btn.label.text = 'Parar';
            this._ponto.visible = true;
            this._ponto.style = `color: ${this._entrada.cor}; margin-right: 4px;`;
            this._icone.visible = false;
            this._atualizarRotulo();
            this._iniciarTick();
        } else {
            this._btn.label.text = 'Iniciar';
            this._ponto.visible = false;
            this._icone.visible = true;
            this._rotulo.text = '';
            this._pararTick();
        }
        this._proxy?.RecentesRemote((r, e) => { if (!e) this._preencherRecentes(JSON.parse(r[0])); });
    }

    _atualizarRotulo() {
        if (!this._entrada) return;
        const dur = fmtDuracao(this._entrada.inicio);
        const aviso = this._entrada.minutos >= 720 || dur.split(':').length === 3 && parseInt(dur) >= 12 ? ' ⚠' : '';
        this._rotulo.text = `▶ ${dur} · ${this._entrada.cliente}${aviso}`;
    }

    _iniciarTick() {
        this._pararTick();
        this._tick = GLib.timeout_add_seconds(GLib.PRIORITY_DEFAULT, 1, () => { this._atualizarRotulo(); return GLib.SOURCE_CONTINUE; });
    }

    _pararTick() {
        if (this._tick) { GLib.source_remove(this._tick); this._tick = 0; }
    }

    destroy() {
        this._pararTick();
        if (this._proxy && this._sinalId) this._proxy.disconnectSignal(this._sinalId);
        this._proxy = null;
        super.destroy();
    }
});
```

- [ ] **Step 4: instalar.sh**

```bash
#!/usr/bin/bash
# Instala o Tempo para o usuário atual. Idempotente. Não usa sudo: imprime o dnf se faltar pacote.
set -euo pipefail
RAIZ="$(cd "$(dirname "$0")" && pwd)"
DEST="$HOME/.local/share/tempo"
BIN="$HOME/.local/bin/tempo"
EXT_UUID="tempo@oguim.com"
EXT_DIR="$HOME/.local/share/gnome-shell/extensions/$EXT_UUID"

echo "== Tempo: instalação em $HOME"

if [ -z "${TEMPO_SEM_GNOME:-}" ]; then
  faltando=()
  for p in gtk4 libadwaita python3-gobject; do rpm -q "$p" >/dev/null 2>&1 || faltando+=("$p"); done
  if [ ${#faltando[@]} -gt 0 ]; then
    echo "Faltam pacotes do sistema. Rode no Terminal e depois execute este script de novo:"
    echo "  sudo dnf install ${faltando[*]}"
    exit 1
  fi
fi

echo "-- app"
mkdir -p "$DEST/app" "$HOME/.local/bin"
rm -rf "$DEST/app/tempo"
cp -r "$RAIZ/app/tempo" "$DEST/app/tempo"
cat > "$BIN" <<EOF
#!/usr/bin/bash
export PYTHONPATH="$DEST/app\${PYTHONPATH:+:\$PYTHONPATH}"
exec python3 -m tempo.app "\$@"
EOF
chmod +x "$BIN"

echo "-- ícone e menu"
mkdir -p "$HOME/.local/share/applications" "$HOME/.local/share/icons/hicolor/scalable/apps" \
         "$HOME/.local/share/dbus-1/services" "$HOME/.config/autostart"
cp "$RAIZ/dados/br.com.oguim.Tempo.svg" "$HOME/.local/share/icons/hicolor/scalable/apps/"
sed "s|^Exec=tempo|Exec=$BIN|" "$RAIZ/dados/br.com.oguim.Tempo.desktop" > "$HOME/.local/share/applications/br.com.oguim.Tempo.desktop"
sed "s|@BIN@|$BIN|" "$RAIZ/dados/br.com.oguim.Tempo.service" > "$HOME/.local/share/dbus-1/services/br.com.oguim.Tempo.service"
{ sed "s|^Exec=tempo|Exec=$BIN --gapplication-service|; /^DBusActivatable/d" "$RAIZ/dados/br.com.oguim.Tempo.desktop"; echo "X-GNOME-Autostart-enabled=true"; } \
  > "$HOME/.config/autostart/br.com.oguim.Tempo.desktop"

echo "-- extensão"
mkdir -p "$EXT_DIR"
cp -r "$RAIZ/extensao/." "$EXT_DIR/"
glib-compile-schemas "$EXT_DIR/schemas/"

if [ -z "${TEMPO_SEM_GNOME:-}" ]; then
  gnome-extensions enable "$EXT_UUID" 2>/dev/null || echo "   (ative a extensão após relogar: gnome-extensions enable $EXT_UUID)"
  update-desktop-database "$HOME/.local/share/applications" 2>/dev/null || true
  gtk-update-icon-cache -q "$HOME/.local/share/icons/hicolor" 2>/dev/null || true
  echo "-- verificação"
  if versao=$(timeout 10 gdbus call --session -d br.com.oguim.Tempo -o /br/com/oguim/Tempo/Servico -m br.com.oguim.Tempo.Servico.Versao 2>/dev/null); then
    echo "Tempo instalado, versão ${versao//[\(\)\',]/}"
  else
    echo "Serviço não respondeu. Faça logout e login para o GNOME carregar a extensão, depois rode: $BIN --gapplication-service &"
  fi
  echo "No Wayland a extensão só aparece depois de sair e entrar de novo na sessão."
else
  echo "Tempo instalado (modo teste, sem GNOME)."
fi
```
